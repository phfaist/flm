# flm-core

`flm-core` is part of the [`flm`](https://github.com/phfaist/flm) project, the Flexible
Latex-like Markup language: it is the core library, which parses a document and renders it
into its outputs.

The source code is at <https://github.com/phfaist/flm>, and the FLM documentation at
<https://docs.rs/flm/latest/flm/>.
